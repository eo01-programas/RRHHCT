CONTROL DE MARCACIONES

Sube la boleta PDF para extraer el código y la hoja de cÁlculo para traer todas las filas y columnas de ese código.

La tabla se arma con las filas del Excel/ODS que coinciden con el código detectado en la boleta PDF.

Sube la boleta PDF para generar la tabla.

La tabla de marcaciones aparecerá aquí cuando cargues la boleta.

CONTROL DE PLANILLA

Selecciona uno o varios archivos de marcacion para mostrar una tabla por cada archivo, con todas las columnas detectadas.

Cada archivo se procesa por separado y se muestra su tabla completa debajo.

Selecciona uno o varios archivos de planilla para ver sus tablas.

Las tablas aparecerán aquí al cargar archivos.
